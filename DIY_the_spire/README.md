# DIY the Spire

击杀尖塔卡牌自定义卡图 Mod。在游戏中为任何卡牌（含其他 Mod 卡）替换普通版和升级版的立绘，支持卡包分类管理和即时切换。

## 功能

- 制作普通版和升级版卡图，二者独立存储。未做升级版时自动沿用普通版
- 内建 Attack / Skill / Power 三种遮罩，制作时自动套用
- 卡包即文件夹，支持新建、重命名、复制、删除，可一键切换或打包分享
- 修改即时生效，无需重启游戏

## 使用方法

1. 百科大全 → 卡牌总览 → 点开任意卡牌
2. 左侧面板选择或新建卡包
3. 点"制作普通版"/"制作升级版"，从本地选图并裁剪即可

全屏模式下弹出窗口可能位于游戏后方，按 Alt+Tab 切出即可。

## 依赖

- ModTheSpire
- BaseMod

## 兼容

通过运行时替换单卡纹理实现，与直接修改底层 Atlas 图集的卡图替换类 Mod 可能存在冲突。纯添加卡牌、遗物的 Mod 不受影响。
